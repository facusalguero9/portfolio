# Change Order Approval → Project Automation

client: technology consulting firm (TechnoMap)

Built a system that chains Zoho CRM's native Approval Process to automatic Zoho Projects creation: once a change order is approved in CRM, the workflow creates the corresponding Phase, Tasklist and Task structure in Projects via the v3 API — no manual re-entry.

Also built and debugged a companion automation handling invoice subform manipulation and keeping status fields in sync across CRM, Projects and Books.

## Stack

Deluge · Zoho CRM Approval Process · Zoho Projects v3 API · Zoho Books custom fields

# Document Generation & E-Signature Automation

client: financial advisory firm (Newpoint Advisors)

Integrated Zoho Writer's merge/sign API with Zoho Sign to auto-generate client documents and route them for signature directly from CRM records, including ownership-transfer logic and custom email templates via merge tags.

Paired it with a WorkDrive folder-automation system tied to CRM Accounts and Client Projects — folders are created, linked, and embedded back into CRM layouts via iframe widgets, so the whole document lifecycle stays inside one screen for the client-facing team.

## Stack

Deluge · Zoho Writer API · Zoho Sign API · WorkDrive API · CRM iframe widgets

# Retail Data Pipeline: Files → CRM Records

client: multi-brand facilities services provider (Gaucher Associates Inc.)

Built Zoho DataPrep pipelines that ingest weekly location and calendar files from major retail brands and automatically create or update Client Project records in CRM — turning a manual, brand-by-brand data-entry process into a scheduled pipeline.

The real difficulty was the data, not the platform: every brand exports in a slightly different shape, with inconsistent address formats and column layouts that needed brand-specific handling before the data could land in a single, consistent CRM schema.

## Stack

Zoho DataPrep · Zoho CRM bulk operations · Zoho Flow

# Positioned PDF Fax Generation

client: healthcare DME provider (DiabetesDME)

Built DocRaptor-based PDF generation flows in Zoho Flow that produce fax-ready documents by absolute-positioning HTML content over background images — matching the exact layout of existing paper forms so the automated version is indistinguishable from a manually filled one.

Later extended the same flow to support a new two-page addendum document by reusing the existing infrastructure through a single docType branch parameter, instead of duplicating the pipeline.

## Stack

Zoho Flow · DocRaptor API · HTML/CSS document templating

# Zoho Flow ↔ SAP Business One Debugging

client: manufacturing/distribution company running SAP B1

Diagnosed a failing Zoho Flow ↔ SAP Business One connector integration running through an On-Prem Agent. Traced the failure to a platform-level serialization bug: Deluge null values were being sent to SAP as the literal string "null" instead of an empty value, silently corrupting records.

Filed a bug report with Zoho and shipped a conditional-branching workaround so the client's integration kept running while the platform fix was pending.

## Stack

Zoho Flow · SAP Business One · On-Prem Agent · Deluge
