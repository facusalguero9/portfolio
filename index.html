# Zoho Flow ↔ SAP Business One Debugging

client: manufacturing/distribution company running SAP B1

Diagnosed a failing Zoho Flow ↔ SAP Business One connector integration running through an On-Prem Agent. Traced the failure to a platform-level serialization bug: Deluge null values were being sent to SAP as the literal string "null" instead of an empty value, silently corrupting records.

Filed a bug report with Zoho and shipped a conditional-branching workaround so the client's integration kept running while the platform fix was pending.

## Stack

Zoho Flow · SAP Business One · On-Prem Agent · Deluge

# Debugging de Zoho Flow ↔ SAP Business One

cliente: empresa de manufactura/distribución que usa SAP B1

Diagnostiqué una integración fallida entre Zoho Flow y SAP Business One, corriendo a través de un On-Prem Agent. Rastreé la falla hasta un bug de serialización a nivel de plataforma: los valores null de Deluge se enviaban a SAP como el string literal "null" en vez de un valor vacío, corrompiendo registros de forma silenciosa.

Reporté el bug a Zoho y entregué una solución alternativa con lógica condicional para que la integración del cliente siguiera funcionando mientras se resolvía a nivel de plataforma.

## Stack

Zoho Flow · SAP Business One · On-Prem Agent · Deluge
